  A simple network toolkit with port scanner, packet sniffer and directory fuzzer.
</p>

---

## Features

- **Web Scanner** — port scan + directory fuzzing
- **Packet Sniffer** — live traffic capture with suspicious port detection

## Requirements

- Python 3.10+
- [Npcap](https://npcap.com/) (for packet sniffer)

## Install

git clone https://github.com/dibofailet-hash/NetTools
cd NetTools
pip install -r requirements.txt

## Usage

python core.py

> Packet sniffer requires admin/root privileges
